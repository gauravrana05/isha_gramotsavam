# Dhrit Platform - Agent Libraries

This directory contains reusable components and patterns for all 8 Dhrit agents.

## Structure

### Design System (Kalp)
- **tokens/**: Design tokens (colors, typography, spacing)
- **components/**: Component specifications
- **layouts/**: Layout patterns
- **patterns/**: UI patterns and guidelines
- **animations/**: Animation specifications
- **brand/**: Brand guidelines and assets

### Frontend (Roop)
- **components/**: React components (UI, forms, layouts)
- **hooks/**: Custom React hooks
- **utils/**: Utility functions
- **animations/**: Animation implementations
- **providers/**: Context providers
- **constants/**: Application constants

## Usage

Agents will populate these libraries with reusable components as they build projects. Each successful implementation gets added to the library for future reuse.
