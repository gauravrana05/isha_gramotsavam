# Agent Libraries

Reusable components, utilities, and templates for each specialized agent.

## Structure

### Frontend Agent Library
- **Components**: Reusable React components (forms, UI, layouts)
- **Hooks**: Custom React hooks for common functionality
- **Utils**: Validation, formatting, and utility functions

### Backend Agent Library
- **Routers**: tRPC router templates and implementations
- **Middleware**: Authentication, rate limiting, validation
- **Utils**: Password, JWT, email utilities
- **Templates**: Code generation templates

### Database Agent Library
- **Schemas**: Prisma schema templates
- **Migrations**: Common database migrations
- **Seeds**: Standard seed data
- **Queries**: Optimized query patterns

### QA Agent Library
- **Tests**: Reusable test suites
- **Configs**: Standard configuration files
- **Utils**: Test helpers and mock data
- **Templates**: Test generation templates

## Usage

Agents will reference these libraries to:
1. Reuse proven components across projects
2. Maintain consistency in code patterns
3. Speed up development with templates
4. Ensure quality with tested components

Each library grows over time as agents create and refine components.
