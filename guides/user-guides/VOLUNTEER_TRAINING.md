# Volunteer Training Materials - Isha Gramotsavam

## 🎯 Training Overview

### Quick Training Format
- **Duration**: 1 hour orientation + hands-on practice
- **Format**: Mobile-friendly demonstration
- **Location**: At assigned venues
- **Materials**: Phone/tablet + printed quick cards

## 📱 Mobile Training Session (1 hour)

### Phase 1: App Basics (15 min)
**On volunteer's phone/tablet:**

#### Login & Navigation
- Download PWA or open web app
- Login with Isha SSO credentials
- Navigate to assigned venue
- Access volunteer guide: `/volunteer/venues/[venueId]/guide`

#### Essential Features Tour
- **Dashboard**: Overview of daily tasks
- **Teams**: Player verification interface
- **Matches**: Score input and results
- **Reports**: End-of-day summaries

### Phase 2: Player Verification (20 min)
**Hands-on practice with test data:**

#### Document Review Process
1. **Access**: `/volunteer/venues/[venueId]/teams`
2. **Review**: Player photos and documents
3. **Decision**: Approve/reject with reasons
4. **Communication**: Send feedback to players

#### Common Scenarios
- **Clear documents**: Quick approval process
- **Unclear photos**: Request resubmission
- **Missing documents**: Guide player on requirements
- **Disputes**: Escalation to admin

### Phase 3: Match Day Operations (20 min)
**Practice with sample matches:**

#### Team Check-in
1. **Access**: `/volunteer/venues/[venueId]/checkin`
2. **Verify**: Team roster and player eligibility
3. **Confirm**: Team readiness for match
4. **Update**: System status

#### Score Recording
1. **Access**: `/volunteer/venues/[venueId]/matches`
2. **Input**: Match scores and results
3. **Verify**: Data accuracy before submission
4. **Confirm**: Tournament bracket updates

### Phase 4: Q&A & Support (5 min)
- Address specific questions
- Share emergency contacts
- Distribute quick reference cards
- Confirm understanding

## 🎯 Venue-Specific Training

### Pre-Tournament Venue Visit
**1 day before tournament:**

#### Venue Familiarization
- **Physical layout**: Courts, facilities, entry/exit
- **WiFi access**: Network credentials and coverage
- **Equipment check**: Tablets, charging stations
- **Emergency procedures**: Medical, security contacts

#### System Setup
- **Test login**: Verify credentials work
- **Data sync**: Ensure offline capability
- **Practice run**: Complete sample workflows
- **Backup plans**: Alternative procedures if system fails

### Day-of-Tournament Briefing
**30 minutes before start:**

#### Daily Objectives
- **Teams to verify**: Number and priority
- **Matches scheduled**: Timeline and expectations
- **Special instructions**: Venue-specific requirements
- **Communication plan**: Check-in schedule with admin

#### Final Checks
- **Device charged**: Battery and backup power
- **App updated**: Latest version installed
- **Contacts saved**: All emergency numbers
- **Materials ready**: Reference cards, pens, forms

## 🔧 Technical Preparation

### Device Requirements
- **Smartphone/Tablet**: Android 8+ or iOS 12+
- **Internet**: WiFi or mobile data
- **Browser**: Chrome, Safari, or Firefox
- **Storage**: 100MB free space for offline data

### App Installation
```bash
# PWA Installation Steps
1. Open browser on device
2. Navigate to: [tournament-url]
3. Tap "Add to Home Screen"
4. App installs like native app
5. Test offline functionality
```

### Offline Capability
- **View data**: Teams, matches, schedules
- **Record scores**: Sync when connection restored
- **Basic verification**: Mark for later review
- **Emergency mode**: Paper backup procedures
