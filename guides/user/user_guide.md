# Isha Gramotsavam - User Guide

## 🎯 Quick Start Guide

### For Players
1. **Register** - Complete your profile with required details
2. **Join/Create Team** - Find existing team or create new one
3. **Upload Documents** - Provide verification documents
4. **Wait for Approval** - Verification volunteers will review
5. **Check Schedule** - View your match schedule once approved

### For Team Captains
1. **Create Team** - Register team for specific sport
2. **Invite Players** - Add team members via phone/email
3. **Manage Roster** - Ensure all players complete verification
4. **Monitor Status** - Track team verification progress
5. **Match Day** - Check in team and view results

### For Volunteers
1. **Login** - Use Isha SSO credentials
2. **Select Venue** - Choose assigned venue/sport
3. **Verify Players** - Review documents and approve/reject
4. **Score Matches** - Input match results in real-time
5. **Generate Reports** - Create daily/event reports

### For Administrators
1. **Setup Events** - Configure tournaments and venues
2. **Assign Volunteers** - Map volunteers to venues/roles
3. **Monitor Progress** - Track registrations and verifications
4. **Manage Issues** - Handle disputes and technical problems
5. **Analytics** - View comprehensive event analytics

## 📱 Mobile App Features

### PWA Installation
1. Open app in mobile browser
2. Tap "Add to Home Screen" 
3. App installs like native app
4. Works offline for core features

### Offline Mode
- View team information
- Check match schedules
- Basic form completion
- Sync when connection restored

## 🆘 Troubleshooting

### Common Issues
**Can't login?** - Ensure using Isha SSO credentials
**Team not showing?** - Check verification status
**Upload failing?** - Try smaller image size
**Page not loading?** - Check internet connection
